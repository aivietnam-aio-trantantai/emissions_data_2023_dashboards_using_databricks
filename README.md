# emissions_data_2023_dashboards_using_databricks
US Greenhouse gas emissions dashboard built with Databricks SQL, analyzing emissions by state, county, and population. 

## About this project: 
This project analyzes greenhouse gas (GHG) emissions across the United States (US) using data collected by the EPA (Environmental Protection Agency). I built an interactive dashboard in Databricks SQL with multiple datasets and charts to explore emissions at the state, county, and per-person level.

The dashboards includes: 
1. A map showing emission by location
2. A scatter plot comparing emissions per person vs. population
3. A ranking of the 10 highest-emitting states
4. A break-down of total emissions by county.
